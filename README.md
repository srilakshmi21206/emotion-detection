# 🎭 Emotion Detection System

An AI-powered web application that detects human emotions from facial images using DeepFace.

## 🚀 Features
- 📸 Upload photo for emotion detection
- 📷 Live webcam capture
- 😊 Detects 7 emotions: Happy, Sad, Angry, Surprise, Fear, Disgust, Neutral
- 🎯 Confidence percentage for each emotion
- 🎵 Music suggestions based on mood
- 🧠 Fun facts about each emotion
- 📝 Emotion history log

## 🛠️ Tech Stack
- Python 3.10
- DeepFace
- Streamlit
- OpenCV
- TensorFlow

## ▶️ How to Run
```bash
pip install -r requirements.txt
streamlit run app.py
```
